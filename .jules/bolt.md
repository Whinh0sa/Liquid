## 2024-05-18 - Caching Intl Instances in React
**Learning:** In React apps, repeatedly calling `toLocaleString` or instantiating `Intl.NumberFormat` or `Intl.DateTimeFormat` inside render loops (especially inside large lists or charts) causes significant performance bottlenecks because these instances are notoriously slow to create.
**Action:** Cache `Intl.*` instances outside the render cycle or in shared utilities (e.g., `lib/format.ts`) and reuse their `.format()` methods. Pay attention to configuration options (like currency styling) to avoid duplicated symbols (e.g. `$$`) when refactoring hardcoded template literals.
